If you are new to [OpenClaw](https://docs.openclaw.ai/start/getting-started), local deployment is usually the easiest way to get started. For long-term usage, cloud deployment is recommended. This guide explains how to deploy an OpenClaw Agent in a local environment and complete the basic configuration required to run Agent Skills.

This article uses **Windows local deployment as an example**, providing step-by-step instructions for installing OpenClaw, running it locally, and connecting a model API. After completing the setup, you will be able to run OpenClaw on your local machine and start using Agent Skills.

The deployment process consists of three main steps:

1. Install Node.js
2. Install OpenClaw
3. Initialize and configure OpenClaw

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />

## Step 1. Install Node.js

OpenClaw requires the **Node.js runtime environment.** Make sure Node.js is installed on your system before continuing.

### 1.1 Check if Node.js is Installed

Open **Command Prompt or PowerShell as Administrator** and run:

```
node -v
```

If a version number appears, for example:

```
v20.x.x
```

Node.js is already installed and you can proceed to the next step.

If the command is not recognized or the version is too old, install the latest Node.js version from [the official website](https://nodejs.org/zh-cn).

After installation, reopen the terminal and run:

```
node -v
```

to confirm that Node.js was installed successfully.

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />


## Step 2. Install OpenClaw

### 2.1 Install OpenClaw Using npm

<img src="https://statics.aipoch.com/public/f/image/image1-a60be952.webp" alt="Install OpenClaw using npm" className="rounded-lg my-4" />

In an **Administrator terminal,** run:

```
npm install -g openclaw@latest
```

This command installs the latest version of OpenClaw globally.

<img src="https://statics.aipoch.com/public/f/image/image2-d259b524.webp" alt="OpenClaw installation complete" className="rounded-lg my-4" />

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />

### 2.2 Install the OpenClaw System Service

<img src="https://statics.aipoch.com/public/f/image/image3-2d6c3af2.webp" alt="Install OpenClaw system service" className="rounded-lg my-4" />

Run the following command to start the installation process:

```
openclaw onboard --install-daemon
```

OpenClaw requires elevated system permissions.

When prompted to allow installation of the system service, type:

```
yes
```

## Step 3. Initialize OpenClaw Configuration

After starting the onboarding process, you will be guided through a few simple configuration steps.

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />

### 3.1 Choose Installation Mode

You will be prompted to select installation mode:

- **QuickStart**
- **Manual**

For this guide, select:

```
QuickStart
```
<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />

### 3.2 Select a Model Provider

Next, choose your model provider.

<img src="https://statics.aipoch.com/public/f/image/image4-4bfa6b84.webp" alt="Select model provider" className="rounded-lg my-4" />

This guide uses **Moonshot AI (Kimi K2.5)** as an example.

After selecting the provider, continue to the next step.

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />

### 3.3 Enter Your API Key

<img src="https://statics.aipoch.com/public/f/image/image5-f4a62ee5.webp" alt="Enter API key" className="rounded-lg my-4" />

You will be prompted to enter your model API key:

```
Enter your API key:
```

Paste your API key and confirm.

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />


### 3.4 Select Channels


Next, choose the channels you want to enable.

<img src="https://statics.aipoch.com/public/f/image/image6-39714155.webp" alt="Select channels" className="rounded-lg my-4" />

Select the channels according to your needs and [continue](https://docs.openclaw.ai/channels).

<div className="my-8 h-0.5 bg-gray-300 dark:bg-gray-600" />

After completing the setup, OpenClaw will be fully configured and ready to use.
You can now start running your Agent and using Agent Skills.
