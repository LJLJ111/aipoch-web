# 统计分析计划（SAP）：阶梯式整群随机试验

> 供研究启动前冻结。遵循 CONSORT 2010 阶梯扩展与 ICH E9。与方案（`10`）、样本量（`11`）配套。

## 一、分析模型（核心）

阶梯设计的核心风险是**时间趋势混杂**，必须显式建模时间效应。

**连续结局（HbA1c）**：线性混合效应模型（LMM）

$$Y_{ijt} = \mu + \beta_t + \theta X_{it} + \alpha_i + \epsilon_{ijt},\quad \alpha_i\sim N(0,\tau^2),\;\epsilon_{ijt}\sim N(0,\sigma^2)$$

- $i$=簇，$j$=个体，$t$=期；$\beta_t$=时间固定效应（**作为分类变量**为主，避免误设线性趋势）；$\theta$=治疗效应；$\alpha_i$=簇随机截距。
- **二分类结局（血压控制率）**：logistic 混合模型或 GEE（可交换相关结构 + 稳健方差）。

**软件**：R `lme4`/`glmmTMB`（LMM/GLMM）或 Python `statsmodels`/`pymer4`；GEE 用 `geepack`/`statsmodels.GEE`。

## 二、分析原则

1. **ITT**：按随机分配分析全部纳入簇与个体，不因实施情况排除；
2. **基线调整**：纳入基线期结局或关键协变量（年龄、性别、基线 HbA1c/血压、县域人口特征）提升精度；
3. **时间效应**：主分析将时间作为**分类**固定效应；敏感性用连续（线性/非线性）趋势；
4. **聚类**：所有推断以簇为聚类单位（稳健/夹心方差或随机效应），避免个体级伪重复；
5. **预设**：全部分析在揭盲/数据锁定前冻结，分析者盲。

## 三、缺失与失访

- 个体缺失：描述缺失模式，多重插补（m=20）作主敏感性；
- 簇失访（乡镇退出）：完整病例 vs 插补对比，报告簇级损耗。

## 四、敏感性分析

1. **treatment × time 交互**：检验干预效应是否随上线时长变化（学习曲线/延迟效应）；
2. **不同时间建模**：时间作分类 vs 连续 vs 分段；
3. **ICC 结构**：可交换 vs 更复杂相关结构；
4. **有限簇校正**：簇数少（<20）时用 Kenward–Roger 自由度校正或置换检验，避免 I 类错误膨胀；
5. **限制性随机化**：纳入随机化分层变量；
6. **离群/影响簇**：逐簇剔除影响分析（leave-one-cluster-out）。

## 五、次要与过程结局

- 次要结局同主模型；规范管理率/转诊率（二分类）用 logistic 混合模型；
- 过程评价（RE-AIM/CFIR）单独报告，不纳入主要功效分析。

## 六、多重比较与报告

- 主要结局单一预设，α=0.05 双侧；次要结局按 Bonferroni 或 Benjamini–Hochberg FDR 校正；
- 报告：效应估计 + 95% CI、簇内相关系数估计、设计效应、流程图（含簇与个体损耗）；
- 遵循 CONSORT 2010 阶梯扩展清单逐条核对。

## 七、数据与代码

- 分析代码版本化；关键分析由第二统计师独立复核；
- 数据按 FAIR 原则去标识化共享（医共体区域健康数据需符合《数据安全法》与医疗数据管理规定）。
