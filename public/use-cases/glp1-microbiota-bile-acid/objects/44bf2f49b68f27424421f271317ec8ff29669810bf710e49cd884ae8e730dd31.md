# 试验方案：可穿戴房颤机会性筛查 + 抗凝决策支持（队列多重随机设计）

> 采用**队列多重随机对照试验（cmRCT / Trials Within Cohorts）**设计：以多中心筛查队列为母体，对新检出房颤患者做抗凝决策支持的嵌入式随机。遵循 CONSORT/STARD 报告规范。

## 一、科学问题与假设

**问题**：可穿戴连续监测能否有效筛查房颤，并且对新检出房颤患者的抗凝决策支持能否提高抗凝启动率（进而改善结局）？

- **H1（筛查）**：可穿戴连续监测在目标人群中能检出有意义比例的新发房颤（检出率 ≥2%），且经 ECG 确认后阳性预测值 ≥70%。
- **H2（嵌入式随机，主要）**：对新检出、有抗凝指征（CHA₂DS₂-VASc ≥2）的房颤患者，抗凝决策支持使 3 个月 OAC 启动率较常规管理绝对提升 ≥15 个百分点。

## 二、研究设计（cmRCT）

```
多中心前瞻队列（母队列）  N≈30,000–40,000
   │  可穿戴连续监测（PPG 不规则心律 + 确认性 ECG）
   ▼
新检出房颤 + CHA₂DS₂-VASc≥2 + 抗凝指征
   │  嵌入式 1:1 随机
   ├── 抗凝决策支持干预组
   └── 常规管理对照组
```

**cmRCT 关键要素**：
- **母队列**：多中心（10–20 家中心）前瞻性招募；
- **嵌入式随机**：在母队列内对新检出房颤者按 1:1 随机（个体级）；
- **分阶段知情同意**：入队时签署队列同意，被随机到干预组时补签干预专项同意（Relton 方法学）；
- **一次队列、多重试验**：母队列基础设施（招募/随访/数据）可复用于未来其他嵌入式试验。

## 三、研究人群

- **纳入（母队列）**：年龄 ≥65 岁（或 ≥55 岁伴 ≥1 项卒中危险因素），无已知房颤，能佩戴可穿戴设备并同意随访。
- **排除**：已确诊房颤/房扑、已长期抗凝、植入起搏器/ICD、预期寿命 <1 年、无法提供知情同意。
- **嵌入式随机纳入**：队列中经 ECG 确认新发房颤、CHA₂DS₂-VASc ≥2、无抗凝禁忌（HAS-BLED 评估）。

## 四、筛查与干预

### 4.1 筛查（可穿戴连续监测）
- 智能手表/腕戴设备 PPG 连续监测 → 不规则心律算法提醒；
- 提醒触发 → 确认性检查（单导联 ECG / 12 导联 ECG / 贴片），由心内科复核确诊；
- 记录：提醒次数、确认结果、假阳性（无房颤）、检出时程。

### 4.2 抗凝决策支持（干预组）
1. 个体化卒中风险（CHA₂DS₂-VASc）与出血风险（HAS-BLED）可视化；
2. 循证抗凝推荐（DOAC 优先）+ 共享决策工具；
3. 基层/专科医师决策支持提醒 + 教育；
4. 随访依从性支持。

**对照组**：常规告知房颤诊断与标准建议，无结构化决策支持。

## 五、结局

- **主要结局（嵌入式随机）**：随机后 3 个月 **OAC 启动率**（启动 DOAC 或华法林）。
- **次要结局**：随机后 12 个月 OAC 依从性（覆盖天数比例 PDC）、卒中/体循环栓塞、大出血、全因死亡、共享决策质量（SDM-Q-9）。
- **筛查结局（队列）**：房颤检出率、阳性预测值 PPV、诊断性能（灵敏度/特异度，以 ECG 为金标准）、假阳性负担、筛查成本。

## 六、随机化与盲法

- **随机化**：中心分层 1:1 随机（区块化），经中央随机系统分配；
- **盲法**：干预性质无法对参与者/临床医师设盲；**结局评估与统计分析设盲**（评估者盲、分析者盲、预设分析计划）。

## 七、样本量（详见 `16`）

- 母队列 ~30,000–40,000（检出率 2% → 600–800 例新检出房颤）；
- 嵌入式随机：+15pp OAC 启动率需每臂 ~169 例（共 ~338），+10pp 需共 ~774；
- 卒中结局（HR 0.36）需 ~500–1500 例 + 2–3 年随访（说明性，非主要结局）。

## 八、伦理、注册与实施

- 伦理批准 + 分阶段知情同意；
- 前瞻性注册（ChiCTR/ClinicalTrials.gov）；
- 数据与算法安全合规（可穿戴健康数据、器械算法审批/注册）；
- 成本效果与假阳性负担的过程评价并行开展。

## 九、局限

1. 筛查干预（连续监测）无法设盲；
2. 抗凝决策支持存在污染风险（同一中心医师可能同时处理两臂患者），必要时可改为临床医师/中心簇随机；
3. OAC 启动率为过程结局，卒中结局需更长随访与更大样本（在次要结局中探索）；
4. 可穿戴设备的人群代表性偏倚（数字鸿沟）。
