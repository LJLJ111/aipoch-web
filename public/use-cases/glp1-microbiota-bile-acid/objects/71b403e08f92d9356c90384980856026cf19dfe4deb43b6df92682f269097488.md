# 试验方案：县域医共体慢病共管数字化干预的阶梯式整群随机对照试验

> 试验方案草案。阶梯设计参数与样本量文档（`11`）及 SAP（`12`）配套。遵循 CONSORT 2010 阶梯扩展报告规范。

## 一、科学问题与假设

**问题**：在县域医共体内，数字化慢病共管干预能否改善高血压与 2 型糖尿病患者的临床结局与共管质量？

- **H1（主要）**：数字化共管干预使目标人群糖化血红蛋白（HbA1c）平均下降 ≥0.4%（或血压控制率绝对提升 ≥10 个百分点），优于常规管理。
- **H2（次要）**：干预提高规范管理率、双向转诊率、基层诊疗能力与患者自我管理依从性。

## 二、研究设计

**阶梯式整群随机对照试验（stepped-wedge cluster RCT）**：以乡镇卫生院/村卫生室为**随机单位（簇）**，随机分配到不同**实施顺序**，所有簇最终均接受干预。

**理由**：(1) 干预属系统级（平台+流程），无法对个体随机；(2) 医共体数字化平台需分批次上线，阶梯设计符合实施逻辑；(3) 所有簇最终受益，降低伦理顾虑与招募阻力。

## 三、设计参数

| 参数 | 取值 |
|---|---|
| 簇（乡镇卫生院）数 I | 20（可 16–24） |
| 步数 S | 4 |
| 观察期 T | 5（基线 + 4 步，每步约 6 个月，总 30 个月） |
| 每簇每期样本 m | 30（每期新抽样的横断面患者） |
| 每步切换簇数 k | 5 |

**设计示意（1=干预，0=对照）**：
```
       期1  期2  期3  期4  期5
簇1-5   0    1    1    1    1
簇6-10  0    0    1    1    1
簇11-15 0    0    0    1    1
簇16-20 0    0    0    0    1
```

## 四、研究人群

- **纳入**：县域医共体辖区常住居民，年龄 ≥18 岁，确诊**高血压**和/或**2 型糖尿病**，且在簇内基层机构建立健康档案、规律随访者。
- **排除**：妊娠、预期寿命 <6 个月、严重认知障碍、无法使用/无家属协助使用数字化工具、计划离开辖区 >6 个月。
- **抽样**：横断面设计，每期从每个簇随机抽取 m=30 例满足标准的患者测量结局（避免个体重复测量造成的相关性偏差；若采用封闭队列则需在 SAP 中改用纵向模型）。

## 五、干预（数字化慢病共管）

**核心组件**（区别于单一 CCDS，采用「数据+协同+分级」多维干预）：
1. **区域健康信息平台**：医共体内患者健康档案、检验/用药数据互通；
2. **慢病共管决策支持 + 分级管理**：高血压/糖尿病临床路径、异常值预警、双向转诊触发；
3. **远程监测与随访**：家庭血压/血糖监测数据回传、医护端随访提醒；
4. **患者端 APP/小程序**：自我监测、用药提醒、健康宣教、在线咨询；
5. **基层能力建设**：上级医院带教、质控反馈。

**对照（常规管理）**：既有基层慢病管理，不接入数字化平台。

**实施保真度**：用 CFIR/RE-AIM 框架开展过程评价（平台使用率、转诊执行率、培训完成度）。

## 六、结局

- **主要结局**：HbA1c（%，连续）；血压控制率（<130/80 或 <140/90 mmHg 达标比例，二分类）。
- **次要结局**：血压/血糖均值、规范管理率、双向转诊率、患者自我管理依从性（Morisky 量表）、基层诊疗能力（问卷）。
- **安全/质量**：低血糖/低血压事件、平台相关不良事件。

## 七、随机化与盲法

- **随机化**：由独立统计师用计算机生成簇的切换顺序；按县域人口规模/基线达标率分层随机（限制性随机化）以平衡基线。
- **盲法**：干预性质决定**无法对实施者与患者设盲**；但**结局评估与统计分析需设盲**（评估者盲、分析者盲），并在方案中预设全部分析。

## 八、伦理与注册

- 伦理委员会批准；由于为系统级改进且最终全员获益，可采用**延迟/滚动知情同意**或簇级同意 + 个体退出权（需伦理确认）。
- 前瞻性注册（ChiCTR/ClinicalTrials.gov），按 CONSORT 阶梯扩展报告。

## 九、局限

1. 阶梯设计对**时间趋势混杂**敏感（需在模型中显式建模时间效应，见 SAP）；
2. 横断面抽样无法捕捉个体纵向变化（若需个体轨迹，改用封闭队列）；
3. 数字化干预无法设盲，存在实施偏倚；
4. 平台上线存在学习曲线，可能引入延迟效应（SAP 敏感性分析检验 treatment×time 交互）。
