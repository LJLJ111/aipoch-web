# 统计分析计划（SAP）：可穿戴房颤筛查 + 嵌入式随机

> 供研究启动前冻结。覆盖筛查诊断性能、嵌入式随机、队列分析与报告规范。遵循 CONSORT（随机）、STARD（诊断）、ICH E9。

## 一、筛查诊断性能（队列部分）

- **金标准**：确认性 ECG（单导联/12 导联/贴片）+ 心内科复核。
- **指标**：灵敏度、特异度、阳性预测值（PPV）、阴性预测值（NPV）、房颤检出率（率及 95% CI，用精确二项）。
- **报告**：遵循 **STARD**，绘制诊断流程图；按年龄/风险分层（CHA₂DS₂-VASc）亚组报告。
- **假阳性负担**：记录假阳性者的后续检查次数、焦虑（量表）与成本。

## 二、嵌入式随机：主要结局分析

- **主要结局**：随机后 3 个月 OAC 启动率（二分类）。
- **主分析**：ITT，logistic 回归（调整中心、CHA₂DS₂-VASc、性别、年龄），报告绝对风险差 + 95% CI、需治数 NNT；
- **敏感性**：PP 集、多变量/倾向加权、缺失数据多重插补。
- **亚组**：预设按卒中风险（CHA₂DS₂-VASc 2–3 vs ≥4）、年龄、DOAC vs 华法林。

## 三、嵌入式随机：事件结局分析（次要）

- 卒中/体循环栓塞、大出血、全因死亡：**Kaplan–Meier + Cox 比例风险**（HR + 95% CI）；
- 竞争风险（出血 vs 卒中）用累积发生函数（Fine–Gray）；
- 依从性：PDC（覆盖天数比例），阈值 ≥80% 定义依从。

## 四、cmRCT 特有分析要点

1. **队列代表性**：比较嵌入式随机参与者与未纳入者的基线差异（选择偏倚评估）；
2. **分阶段知情同意的合规**：报告各阶段同意率与退出；
3. **污染**：若同中心医师同时管理两臂，评估干预泄漏（必要时改簇随机，SAP 预留簇级分析方案）；
4. **多重试验框架**：母队列数据字典与分析环境，供未来其他嵌入式试验复用。

## 五、样本量再评估与中期

- 依据预试验校准检出率与 PPV，必要时重估母队列规模；
- 嵌入式随机设独立数据监查委员会（DMC），预设中期分析与停止规则（效能/无效）。

## 六、多重比较与报告

- 主要结局单一预设，α=0.05 双侧；次要结局按 Benjamini–Hochberg FDR 校正；
- 报告 CONSORT（随机）+ STARD（诊断）+ 器械算法描述；
- 分析代码版本化，关键分析由第二统计师复核。

## 七、数据合规

- 可穿戴健康数据、ECG 数据去标识化；符合《个人信息保护法》《数据安全法》及医疗器械（算法）管理要求。
