# 统计分析计划（Statistical Analysis Plan, SAP）

> 本文档为研究方案（`02_研究方案设计.md`）的统计细节扩展，供研究启动前冻结，减少事后分析偏倚。

## 一、分析人群与定义

- **全分析集（FAS）**：所有入组且至少完成基线多组学采样与一次 GLP-1RA 给药的受试者。
- **符合方案集（PP）**：完成 52 周随访、依从性 ≥80%、无重大方案违背者（用于敏感性）。
- **结局**：主要 = 52 周 %TBWL（连续）；分类 = 非应答 <5% / 中等 5–15% / 超应答 >15%；次要 = 16 周 ≥4% 早期反应、52 周 ≥10% 达标率。

## 二、软件、版本与随机种子

- 语言/版本：R ≥4.3（`glmnet`、`randomForest`、`caret`、`pROC`、`calibration`）或 Python 3.12（`scikit-learn`、`statsmodels`、`shap`）；本次原型为纯 NumPy 实现。
- 随机种子：数据划分、交叉验证、Bootstrap 均固定种子并记录。
- 分析时间：入组完成前冻结 SAP，事后变更需记录版本与理由。

## 三、多组学数据预处理

1. **菌群**：相对丰度 → CLR 变换（`compositions` 包 / 手动 log-ratio）；过滤低丰度（<0.1% 且 <10% 样本）；可选 ILR 平衡。
2. **胆汁酸**：浓度 → log10；低于检出限（LOD）按 LOD/√2 插补；标准化为 nmol/L 或 ng/mL。
3. **批次效应**：测序批次/代谢组板次作为固定效应纳入，或 ComBat 校正（含随机化批次 + 内标 + 质控样）。
4. **缺失值**：<5% 用多重插补（m=20），≥5% 评估缺失机制（MCAR/MAR/MNAR）。
5. **衍生特征**：TGR5 激动指数 = 次级 BA（LCA+DCA+UDCA）；FXR 激动指数 = 初级 BA（CDCA+CA）；次级/初级 BA 比值；BSH 基因丰度。

## 四、主要结局分析

- **连续结局（%TBWL）**：线性回归（基线 BMI、HbA1c、性别、糖尿病状态、药物、年龄为强制协变量）；检验菌群/BA 特征的增量解释力（ΔR²、似然比检验）。
- **分类结局**：L2/L1 正则化逻辑回归（主，可解释）；随机森林/XGBoost（探索非线性）；报告 AUC、敏感度/特异度、Brier 分数、校准曲线、决策曲线。
- **嵌套模型比较**：M0 临床 → M1 +菌群 → M2 +胆汁酸 → M3 全组学；用 DeLong 检验比较 AUC，用似然比检验比较嵌套模型。

## 五、建模与验证细节

- **内部验证**：重复 5 折分层交叉验证（重复 50–100 次），报告 AUC/R² 的 mean±SD。
- **外部验证**：冻结模型，验证队列原样套用；报告性能衰减（ΔAUC）与校准截距/斜率。
- **过拟合控制**：正则化强度（λ）通过嵌套交叉验证选择；避免在同一数据上既选 λ 又评估性能（双重数据泄漏）。
- **不确定性**：Bootstrap（≥2000 次）计算 AUC/R² 的 95% 百分位 CI。

## 六、多重比较与样本量再确认

- 单变量筛选的 P 值用 Benjamini–Hochberg FDR 校正；
- 亚组分析预先指定（性别、糖尿病状态、药物），避免数据驱动亚组；
- 样本量基于「多组学模型较临床模型 AUC 提升 ≥0.10」的假设（见方案），最终功效在完成入组后以观测效应量复核。

## 七、敏感性分析

1. PP 集与 FAS 集结果一致性；
2. 按药物、性别、糖尿病状态分层报告（见扩展建模 2.5 节示例）；
3. 排除早期停药者、排除使用益生菌/抗生素者；
4. 不同非应答阈值（<5% vs <10%）与不同观察时点（16/52 周）；
5. 缺失值方法敏感性（完全病例 vs 多重插补）。

## 八、因果/中介分析（阶段 III）

- **孟德尔随机化**：以菌群（MiBioGen）与胆汁酸相关遗传变异为工具变量，检验其对减重应答的因果效应（双样本 MR，逆方差加权 + MR-Egger + 加权中位数做敏感性）。
- **纵向中介**：交叉滞后面板模型检验「基线菌群/BA → 早期反应 → 52 周减重」的中介路径。

## 九、报告规范

- 遵循 **TRIPOD（多变量预测模型报告规范）** 与 **STROBE**；
- 数据与代码按 FAIR 原则公开；
- 关键分析由第二统计师独立复核。
