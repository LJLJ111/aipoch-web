# 研究方案设计：基于肠道菌群–胆汁酸代谢轴预测 GLP-1RA 减重应答

> 本文档为可执行的研究方案（protocol）草案，供伦理审查与立项参考。设计与文献综述（`01_文献综述与证据综合.md`）一致，直接针对其中的研究空白。

## 一、科学问题与假设

**核心科学问题**：基线肠道菌群与胆汁酸代谢谱型能否解释并预测 GLP-1 受体激动剂（GLP-1RA）的减重应答异质性？

**主要假设（H1）**：基线「菌群–胆汁酸轴」特征（TGR5 激动型次级胆汁酸富集 + FXR 激动型初级胆汁酸降低 + Akkermansia 等促 GLP-1 菌富集）可显著提升对「应答 vs 非应答」的预测力（相对纯临床模型 AUC 提升 ≥0.10）。

**次要假设**：
- **H2**：胆汁酸谱型比菌群丰度更稳健（机制更接近上游信号），胆汁酸 TGR5/FXR 激动比值（如 LCA+DCA / CDCA+CA）为最强单一预测变量。
- **H3**：早期（16 周）减重反应由基线菌群-胆汁酸特征与治疗反应协同决定，可构建「基线 + 早期反应」的动态预测模型。

## 二、研究设计（总体框架）

采用**「前瞻性发现队列 + 独立外部验证队列 + 机制亚研究」**三阶段设计：

```
阶段 I  前瞻性发现队列（单中心，n≈400）
        ├─ 基线多组学（临床/菌群/胆汁酸）采集
        ├─ 启动 GLP-1RA（司美格鲁肽 2.4mg/w 或利拉鲁肽 3.0mg/d）
        └─ 随访 52 周：早期反应(16w) + 主要终点(52w)
阶段 II 独立外部验证队列（多中心，n≈200）→ 冻结模型，外部验证
阶段 III 机制亚研究（n≈60 子样本）→ 因果/中介分析
```

**设计类型**：前瞻性、观察性（预测建模）队列；机制亚研究嵌入纵向采样。

## 三、研究人群与纳排标准

**纳入标准**：
1. 年龄 18–70 岁；
2. BMI ≥30 kg/m²（或 ≥27 kg/m² 伴 ≥1 项体重相关合并症）；
3. 因肥胖新处方司美格鲁肽（2.4 mg/w）或利拉鲁肽（3.0 mg/d）者；
4. 能完成基线与随访采样、签署知情同意。

**排除标准**：
1. 既往减重手术史；
2. 近 3 个月使用抗生素、益生菌、胆汁酸类药物（如熊去氧胆酸、奥贝胆酸）或质子泵抑制剂（影响菌群/胆汁酸）者；
3. 1 型糖尿病、妊娠/哺乳、活动性胃肠或肝胆疾病；
4. 治疗前 3 个月内体重变化 >5%（避免近期主动减重干扰）。

**关键协变量采集**：年龄、性别、基线 BMI、腰围、HbA1c、糖尿病状态与病程、合并用药（二甲双胍、SGLT2i、胰岛素等）、饮食（FFQ）、运动、心理（PHQ-9 抑郁、焦虑）、月经/绝经状态。

## 四、样本量估算

基于文献综述中的真实世界应答分布（非应答 ~18%）：

- 假定发现队列应答率 ~80%（约 20% 非应答）；
- 目标：多组学模型相对临床模型 AUC 提升 ≥0.10（0.70→0.80）；
- 双侧 α=0.05、检验效能 1−β=0.90，预测变量数 p≈25（事件数/变量 ≥10 的准则，非应答事件 n≈80）→ **发现队列 n≈400**；
- **验证队列 n≈200**（确保外部验证有 ≥40 例非应答事件）。
- 机制亚研究 n≈60（子样本，配对纵向采样，功效按中介效应估算）。

## 五、数据与生物样本采集

**时点**：基线（T0）、16 周（早期反应）、52 周（主要终点）。

### 5.1 肠道菌群
- **样本**：粪便（T0/T16/T52），DNA 提取 → **16S rRNA V3–V4 扩增子测序 + 宏基因组鸟枪法测序**（功能基因/菌种水平）。
- **关键输出**：α/β 多样性；菌种相对丰度（重点关注 Akkermansia muciniphila、Clostridium sensu stricto、Bacteroides、Bifidobacterium、Firmicutes/Bacteroidota 比值）；胆汁盐水解酶（BSH）基因丰度；功能通路（KEGG/MetaCyc）。

### 5.2 胆汁酸代谢组（靶向）
- **样本**：空腹血清 + 粪便，LC-MS/MS 靶向定量 **≥20 种 BA 亚型**。
- **关键输出**：初级 BA（CA、CDCA）与次级 BA（DCA、LCA、UDCA）、牛磺/甘氨结合型（TCA、GDCA 等）、合成标志物 **C4（7α-hydroxy-4-cholesten-3-one）**。
- **衍生指标**：TGR5 激动指数 = Σ(次级 BA)；FXR 激动指数 = Σ(初级 BA)；次级/初级 BA 比值。

### 5.3 其他组学（探索）
- 血清非靶向代谢组（复现/验证艾塞那肽研究中的 carnitine/LysoPC/PC 标志物）；
- 可选：FGF19、GLP-1、PYY 等肠激素；GLP1R/GIPR 关键 SNP（rs6923761、rs10305492、rs1800437）基因分型。

## 六、结局定义

- **主要结局**：52 周总减重百分比 %TBWL（连续）。
- **分类结局**：非应答 <5%TBWL；中等应答 5–15%；超应答 >15%（与 PMID 39819958 一致）。
- **次要结局**：16 周早期反应（≥4%）；52 周 ≥10% 达标率；停药后 12 周体重反弹幅度（机制亚研究）。

## 七、统计建模与分析计划

1. **数据预处理**：菌群相对丰度 → CLR/ILR 变换（或 log-ratio）；胆汁酸 → log10 浓度；缺失值多重插补。
2. **模型族**（嵌套比较）：
   - M0 临床基线（年龄/性别/BMI/HbA1c/T2D/病程）；
   - M1 临床 + 菌群；
   - M2 临床 + 胆汁酸；
   - M3 临床 + 菌群 + 胆汁酸（全组学）。
3. **算法**：L2 正则化逻辑回归（主，可解释）；随机森林/XGBoost（探索非线性）；弹性网络（变量选择）。
4. **评估**：5 折重复交叉验证（内部）；独立验证队列（外部）；报告 AUC、敏感度/特异度、校准曲线（calibration）、决策曲线。
5. **可解释性**：标准化系数 / SHAP / 置换重要性，识别核心菌种与 BA 亚型。
6. **中介/因果（阶段 III）**：以孟德尔随机化（菌群/BA 相关遗传工具变量）与纵向交叉滞后面板模型，检验菌群-胆汁酸-GLP-1 减重应答的因果方向。

## 八、独立验证策略

- **外部验证**：冻结发现队列模型，在多中心验证队列原样套用，评估性能衰减；
- **时间验证**：发现队列内部按时间分半；
- **敏感性分析**：按药物（司美格鲁肽 vs 利拉鲁肽）、糖尿病状态、性别分层，检验模型稳健性。

## 九、时间线与里程碑

| 时间 | 里程碑 |
|---|---|
| 0–6 月 | 伦理审批、队列启动、基线入组采样 |
| 6–12 月 | 入组完成、T16 早期反应评估 |
| 12–24 月 | T52 主要终点、组学测序/代谢组检测 |
| 24–30 月 | 建模与内部验证、外部验证队列数据回传 |
| 30–36 月 | 机制亚研究、论文撰写与数据共享 |

## 十、伦理、数据管理与局限

- **伦理**：伦理委员会批准 + 知情同意；组学数据去标识化；GEO/代谢组学公共库沉积（符合 FAIR）。
- **预期局限**：(1) 观察性设计无法直接推断因果（由阶段 III 孟德尔随机化部分弥补）；(2) 药物/饮食混杂（通过协变量调整与敏感性分析）；(3) 菌群/BA 检测成本与批次效应（引入内标、阳性/阴性对照、随机化批次）；(4) 单药物为主的发现队列可能限制跨药物泛化。
